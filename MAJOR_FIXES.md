## P0 - Критично: бот тихо умирает при долгой работе без оператора

Объясняет лонг-тест (частая капча, лаги, тишина). Назвали все ревьюеры.

1. Дедлок пула вкладок: onboarding + мультиподписка + _probe_clear
   запрашивают вкладок больше PAGE_POOL_SIZE; Queue.get() без таймаута
   вешает монитор. Файлы: scraper/browser.py, monitor.py.
2. Нет авто-перезапуска браузера: краш Chromium/контекста -> _ctx не
   None -> start() не пересоздаёт -> вечный парсинг пустоты.
   Файл: scraper/browser.py.
3. Синхронный CLIP/torch/PIL в event loop морозит aiogram, проверку
   капчи и таймеры. Нужен asyncio.to_thread. Файлы: ai/clip_engine.py,
   ai/images.py.
4. Капча ждёт вечно (CAPTCHA_MAX_WAIT_SEC=0) + хрупкий детект
   блокировки (подстроки captcha/datadome есть в легитимных бандлах).
   Файлы: scraper/browser.py, scraper/parser.py.
5. Нет watchdog-алерта: бан IP / зависший цикл / 0 сделок часами -
   пользователю ничего не приходит. Файл: monitor.py.
6. Рост БД без ретенции + O(n)-скан хэшей (5000 строк на лот):
   деградация за часы/дни. Файл: storage.py (image_hashes,
   price_observations, listings, card_state, sent_alerts).

## P1 - Деньги: убыточный лот показывается как сделка

7. Замок оператора / Neverlock / sim-lock не детектится (только
   iCloud). Залоченный айфон -30..50%, не перепродаётся в РФ -> ложная
   жирная скидка. Файлы: ai/specs.py, valuation/scam.py,
   valuation/engine.py.
8. Версия (ростест/реф/восстановл/СНГ/китай/eSIM-only) не входит в
   идентичность устройства и в обучение цены -> база кривая, ложный
   профит. is_rostest извлекается, но нигде не используется.
   Файлы: ai/normalize.py, valuation/devices.py, valuation/engine.py.
9. Свап-экран: True Tone используется только как негатив; визуальная
   трещина (CLIP) меняет доверие только при слове "идеал", иначе
   состояние good и профит как за целый. Файлы: ai/specs.py,
   valuation/scam.py, valuation/engine.py.
10. АКБ: не парсятся циклы, не ловится "100% при 600 циклах", порог
    BATTERY_DEFECT_THRESHOLD=80 глобальный (для 11 79% норм, для 15
    85% звоночек). Файлы: ai/specs.py, config.py.
11. for_parts / faceid_broken глушат чинибельные гемы ("не включается,
    шлейф/АКБ" за 8-12к; Face ID -5..8к торг) вместо оценки downside.
    Файлы: ai/condition.py, valuation/engine.py.
