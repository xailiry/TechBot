# TechHunter Bot

Телеграм-бот для перекупов техники. Следит за свежими объявлениями на
Avito, сам учит реальную рыночную цену по состоянию и присылает только
те лоты, на которых реально можно заработать, включая битые телефоны под
ремонт.

Цены бот не выдумывает: он считает их из настоящих частных объявлений и
постоянно уточняет, чем дольше работает.

---

## Что умеет

- Мониторит Avito в видимом браузере (так почти не прилетает капча; если
  прилетела, бот ставит цикл на паузу, просит решить её вручную в одном
  окне и сам продолжает).
- Распознаёт модель, память, ОЗУ, процент АКБ и дефекты прямо из текста
  и характеристик объявления.
- Сам строит рыночную цену отдельно по каждой памяти и по каждому
  состоянию (идеал / хорошее / с дефектом / битый / на запчасти),
  отсекая магазины, реф и накрутку.
- Считает выгоду: для рабочих по разнице с рынком, для битых по схеме
  "рынок минус цена минус ремонт".
- Защита от мусора и мошенников: реплики, iCloud-замок, переклеенные
  фото, подозрительно низкая цена у "рабочего".
- Гибкая доставка: фильтры по score, по состоянию, скрытие магазинов,
  пауза, пороги профита.
- Удобный интерфейс: меню с кнопками, навигация "Назад", карточка лота
  с уверенностью оценки, цены по состояниям, кнопки обратной связи.

## Как это работает

1. Добавляешь подписку (например `iphone 15 pro | до:55000 | москва`).
2. Бот делает разовый глубокий обход рынка по этой модели и строит
   стартовые цены, затем продолжает учиться в фоне.
3. Когда появляется свежий лот дешевле рынка, приходит карточка с
   ценой, профитом, отчётом о состоянии и ссылкой на объявление.

## Стек

Python 3.13, asyncio, aiogram 3, Playwright (видимый Chromium),
SQLAlchemy 2 (async) + Alembic, Pydantic 2, BeautifulSoup, локальный
CLIP (torch / transformers) для проверки фото, SQLite.

## Установка

```bash
python -m venv venv
venv\Scripts\activate            # Windows
pip install -r requirements.txt
python -m playwright install chromium

copy .env.example .env           # и впиши BOT_TOKEN
python -m alembic upgrade head
python main.py
```

`BOT_TOKEN` берётся у @BotFather. Прочие настройки (пороги профита,
города, тайминги обхода, фильтры) задаются через переменные окружения,
список и значения по умолчанию смотри в `techhunter/config.py`.

## Команды и кнопки

`/start` или `/menu` открывает главное меню. Дальше всё кнопками:
подписки, добавление, настройки доставки, статус, цены по состояниям,
качество. Команды `/add`, `/list`, `/del`, `/pause`, `/resume`,
`/settings` остаются как быстрые ярлыки.
